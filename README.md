# 吸入指導報告書アプリ

`吸入指導報告書.docx` の内容を、iPhone のタップ操作だけで作成して PDF 保存・印刷できるようにしたアプリです。
HTML 1 枚で動く PWA（ホーム画面に追加して使うアプリ）で、サーバーや月額費用は不要です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・ロジック・報告書レイアウトをすべて含む） |
| `manifest.json` | ホーム画面に追加したときのアプリ名・アイコン設定 |
| `sw.js` | オフラインで動かすためのサービスワーカー |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アプリアイコン |

## iPhone で使えるようにする手順

### 手順 A：静的ホスティングに置く（推奨・ホーム画面に追加できる）

1. このフォルダごと、無料の静的ホスティングにアップロードします
   （Netlify Drop、Cloudflare Pages、GitHub Pages など。フォルダをドラッグ＆ドロップするだけのサービスが簡単です）
2. 発行された URL を **iPhone の Safari** で開きます（Chrome ではホーム画面追加が正しく動きません）
3. 画面下の **共有ボタン（□に↑）** → **「ホーム画面に追加」**
4. ホーム画面に「吸入指導」アイコンができます。以降はアイコンから起動でき、圏外でも動作します

> **フルスクリーン起動にしていない理由**
> iOS のフルスクリーン（standalone）起動ではSafariの共有・プリントボタンが消えてしまい、
> PDF保存・印刷が一切できなくなります。このアプリはPDF出力が目的のため、
> ホーム画面から起動してもSafariの操作バーが残る設定にしてあります。

### 手順 B：とりあえず試す（ホーム画面追加なし）

`index.html` を iCloud Drive などに置き、iPhone の「ファイル」アプリから Safari で開きます。
機能は一通り動きますが、ホーム画面への追加とオフライン動作は保証されません。

> ホスティング先が決まっていなければ、そのまま伝えていただければ設定手順を具体的に用意します。

## 使い方

**すべての項目が 1 ページに並んでいます。**上から順にスクロールしながら入力してください。
画面上部のバー（宛先／患者／総合評価／手技／理解度／連絡事項／コメント／確認）を押すと、その位置へ一気に移動できます。
画面下には常に **「プレビュー」** と **「PDF保存・印刷」** ボタンが表示されているので、どこにいても出力できます。

| セクション | 内容 |
|---|---|
| **報告日・宛先** | 報告日／病院・クリニック名／医師名／薬局 |
| **患者・担当薬剤師** | 患者名／担当薬剤師 |
| **吸入指導の総合評価** | 3 択 |
| **吸入手技の評価** | 指導した薬剤（1〜2剤）と、6 項目の ○ / ✕ 評価 |
| **吸入療法の理解** | 4 項目の 良好 / 不良 |
| **医師への連絡事項** | チェック項目と付随する自由記入 |
| **コメント** | 報告書の最後に印字される自由記入欄 |
| **確認・出力** | 報告書の仕上がりをその場で確認して PDF 保存・印刷 |

一番下のプレビューは入力すると**即座に反映**されます。○ / ✕ などを押しても画面はその場に留まり、スクロール位置は動きません。

### 入力のポイント

- **選択ボタンはもう一度押すと解除**できます（○ を押し直すと空欄に戻ります）
- **病院・クリニック名**は「一覧から選択」と「自由入力」を切り替えられます
- **薬局**を切り替えると連絡先が自動で入ります
  - フレンド薬局：TEL 03-5548-5548 / FAX 03-5548-5547
  - サン薬局：TEL 03-3683-7950 / FAX 空欄
- **コメント**は入力したときだけ報告書の最後に印字されます

### PDF にする

画面下の **「PDF保存・印刷」**（または一番下の確認セクションのボタン）→ プリンタ選択画面が開きます。
プレビュー部分を **ピンチで拡大**（または長押し）すると PDF ビューになるので、
共有ボタンから「ファイルに保存」を選べば PDF が保存できます。
AirPrint 対応の FAX 複合機があれば、この画面からそのまま印刷・送信できます。

## 名前の登録（設定）

右上の **「設定」** から、以下を追加・削除できます。追加した内容は次回以降も残ります。

- **病院・クリニックと医師名** … 施設を登録し、その施設ごとに医師名をぶら下げて登録します
- 薬剤師
- 吸入薬（初期状態で主な吸入薬を登録済み。「初期状態に戻す」で戻せます）

### 医師名は病院・クリニックと連動します

入力画面で病院・クリニックを選ぶと、**その施設に登録された医師名だけ**が候補に出ます。
候補にない医師のときは「自由入力」に切り替えるか、「＋登録」でその施設に追加してください。
施設を選び直すと、前の施設の医師名は自動的に外れます。

入力画面内の **「＋登録」** ボタンからその場で追加することもできます。

### PDF保存・印刷が反応しないとき

ホーム画面のアイコンが**フルスクリーン起動**として作られていると、iOS の共有・プリントバーが出ず PDF 保存ができません。
アイコンを作った時点の設定がそのまま固定されるため、ファイルを更新しただけでは直りません。

**直し方：ホーム画面のアイコンを一度削除して、追加し直してください。**

1. ホーム画面のアイコンを長押し →「ブックマークを削除」
2. Safari で URL を開き直す
3. 共有ボタン →「ホーム画面に追加」

追加し直すと Safari の操作バーが残る状態で開くようになり、印刷が使えます。
なお、フルスクリーンで起動している間は確認セクションに **「Safariで開く」** ボタンが表示されるので、
そこから開き直すこともできます。

## データの取り扱い

- 入力内容・登録した名前は、**その iPhone の Safari 内にのみ**保存されます。
  外部サーバーには一切送信されません（通信を行うコードは含まれていません）。
- 入力途中の内容は自動保存され、アプリを閉じても復帰します。
  次の患者に移るときは右上の **「新規」** で消去してください。
- Safari の「履歴とWebサイトデータを消去」を実行すると、登録した名前と下書きも消えます。
- 患者名を含むため、端末のパスコード／Face ID は必ず有効にしてご利用ください。

## 変更したいとき

すべての設定値は `index.html` の先頭付近にまとまっています。

- `DEFAULT_MASTERS` … 吸入薬の初期リスト
- `PHARMACIES` … 薬局名・TEL・FAX
- `SKILL_ITEMS` / `UNDER_ITEMS` / `OVERALL_OPTS` / `SYMPTOMS` … 各評価項目の文言
